# Security Policy

## Supported versions

Security fixes are provided for the latest published Miles release.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub Security Advisories:

1. Open the repository's **Security** tab.
2. Select **Advisories** and **Report a vulnerability**.
3. Include affected versions, reproduction steps, impact, and any suggested
   mitigation.

Do not disclose an unpatched vulnerability in a public issue. Please do not
include private media, cookies, tokens, personal paths, or expiring YouTube
stream URLs in a report.

Reports concerning command or option injection, path traversal, sidecar supply
chain integrity, unsafe file parsing, or CSP bypasses are especially helpful.

## Scope notes

Miles is a local desktop application without accounts, telemetry, a hosted API,
or a cloud database. Third-party service availability and platform policy
changes are outside the project's control.
